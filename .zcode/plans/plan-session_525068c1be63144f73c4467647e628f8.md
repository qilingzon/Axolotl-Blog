# 紫粉美西螈主题博客 · Astro 实施方案

## 设计概念

以 Minecraft 紫色 + 粉色美西螈为灵感的通用个人博客「**美西螈池塘 Axolotl Pond**」。两只手绘像素美西螈（紫螈 + 粉螈）作为博客吉祥物贯穿全站：logo、首页 hero、关于页人设、404 彩蛋、favicon。所有美术均为手写 SVG 像素画（无外部图片依赖，离线可用）。

## 三个可切换主题（localStorage 持久化，导航栏切换按钮）

| 主题 | 风格 | 要点 |
|---|---|---|
| `pink-soft` 粉螈·奶油（默认） | 现代柔和风 | 暖粉底色、大圆角卡片、紫粉渐变点缀、漂浮气泡装饰 |
| `purple-pixel` 紫螈·像素 | Minecraft 像素风 | 方块感（零圆角+硬阴影偏移）、像素字体标题、游戏 UI 式按钮、紫色主导 |
| `lumen-cave` 荧光洞窟 | 深色夜读 | 繁茂洞穴深色底、紫粉荧光发光效果 |

实现方式：`global.css` 用 `[data-theme=...]` 定义 CSS 变量（颜色/圆角/字体/阴影）+ 结构性覆盖；`<head>` 内联脚本在首帧前读 localStorage 设置主题（防闪烁）。

## 站点结构（纯静态，Astro v5）

```
src/
├── config.ts                     # 站名、导航等站点配置
├── content.config.ts             # 内容集合（glob loader + zod schema）
├── content/blog/*.md             # 6 篇中文占位文章（开张公告/建站手记/像素画教程/MC美西螈参观记等）
├── layouts/BaseLayout.astro      # html 骨架 + 主题引导脚本
├── components/
│   ├── Header.astro / Footer.astro
│   ├── ThemeSwitcher.astro       # 三主题循环切换
│   ├── Axolotl.astro             # 参数化像素美西螈 SVG（体色/腮色可配）
│   └── PostCard.astro
├── pages/
│   ├── index.astro               # hero（双螈吉祥物）+ 最新文章
│   ├── blog/index.astro          # 文章列表
│   ├── blog/[slug].xml → [slug].astro  # 文章页（上一篇/下一篇）
│   ├── about.astro               # 紫螈粉螈双"博主"人设介绍
│   └── 404.astro                 # 美西螈迷路彩蛋
└── styles/global.css             # 三主题变量与样式
```

字体策略：正文走系统字体栈（离线可读）；像素主题标题用缝合像素字体（Fusion Pixel，jsdelivr CDN woff2 分片），加载失败自动回退 Press Start 2P/系统字体。

## 实施步骤（每步一个 commit，遵循大文件分块写入纪律）

1. **脚手架**：从 `D:\zcodework\_template` 复制 AGENTS.md/HANDOFF.md/backup.sh（替换项目名）；手写 Astro 最小工程（package.json/astro.config.mjs/tsconfig，仅 `astro` 一个依赖，不用交互式 create-astro）；`npm install` + 占位首页 `npm run build` 验证通过后 commit `init`，跑 `bash backup.sh` 做仓库外 bundle 备份。
2. **主题系统**：global.css 三套主题 + 切换器 + Header/Footer/BaseLayout。
3. **美西螈美术**：Axolotl 像素 SVG 组件（16 网格、crispEdges、体色参数化）、favicon.svg、hero 场景、气泡/水草装饰。
4. **页面与内容**：四个页面 + 404 + 内容集合 + 6 篇占位文章。
5. **验收**：`npm run build`（退出码 0）→ `astro preview` → 浏览器截图证据：3 主题 × 首页/列表/文章页 + 移动端宽度 + 刷新后主题持久；修完问题后更新 HANDOFF.md，最终 commit + bundle 备份。

## 验收标准

- `npm run build` 成功，产出 dist/
- 三主题切换正常、刷新保持、无闪烁
- 首页/列表/文章/关于/404 全部可导航，移动端不破版
- 截图证据留档，git 提交完成，bundle 备份落盘

## 风险与对策

- Astro 大版本 API 差异：以 `npm i astro` 实际安装版本的官方 content collections 用法为准，实现时核对。
- CDN 字体不可达：回退栈保证像素主题仍可读（圆角/阴影等像素感不依赖字体）。
