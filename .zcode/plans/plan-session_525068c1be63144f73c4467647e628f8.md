# 美西螈 CMS —— 全中文定制后台（EdgeOne Pages 版，接管 /admin）

## 架构（部署目标：腾讯云 EdgeOne Pages，国内访问快）

```
浏览器（/admin 中文 SPA，博客同皮肤：三主题/像素字/七色美西螈）
   │ ①POST /api/login → 校验环境变量账号密码 → 发 HMAC 签名 token（12h）
   │ ②Bearer token 调 /api/posts、/api/media
EdgeOne Pages 边缘函数（edge-functions/api/*.js，onRequest* 处理器）
   │ ③服务端持 CMS_GITHUB_TOKEN 调 GitHub Contents API（token 不出服务端）
GitHub commit ──► 自动构建（EdgeOne Pages 或现有 Cloudflare Pages 均可触发）
```

博客整站（含 CMS）一起部署 EdgeOne Pages：控制台接入 GitHub 仓库，构建命令 `npm run build`、产物 `dist/`，环境变量在项目设置里配 4 个：`CMS_USERNAME`、`CMS_PASSWORD`、`CMS_SESSION_SECRET`、`CMS_GITHUB_TOKEN`（可直接粘贴 `gh auth token` 输出）。若博客暂留 Cloudflare，仅 CMS 部署 EdgeOne 也可行（同源访问 API 不受影响）。

## EdgeOne 适配要点（已查证官方文档）

- 函数目录 `edge-functions/`，文件路由含 `[slug].js` 动态参数，`onRequestGet/Post/Put/Delete(context)` 导出，`context = {request, params, env, waitUntil}`，标准 Web API（fetch/Request/Response/crypto.subtle）
- **请求体 ≤1MB**：媒体上传做浏览器端自动压缩（Canvas 限宽 1600px + JPEG/WebP 质量 0.85，目标 ≤900KB），博客图片本来就不需要更大——顺势成为功能
- CPU 200ms / 代码包 5MB：我们的函数只是签名校验 + GitHub API 转发，余量充足
- 本地调试：`npm i -D edgeone`，`edgeone makers dev`（.env 读取方式实现时验证，不支持则用 CLI 参数/本地 dev 配置兜底）

## 功能清单（全中文）

1. **登录页**：大美西螈+气泡+像素字「美西螈 CMS」，错误提示、登录态记住（localStorage，过期自动登出）、失败限速
2. **仪表盘**：文章数/标签数/最近更新统计 + 最新文章
3. **文章列表**：搜索、标签筛选、每行对应色美西螈头像、草稿标记
4. **编辑器**：标题/摘要/日期/标签表单 + **七色美西螈可视化选择器**（色块即头像预览）+ 草稿开关；Markdown 工具栏（标题/粗斜/链接/代码/引用/表格）+ 分屏实时预览（预览区可切三主题）；保存/删除走中文 commit message（「CMS: 更新《标题》」）
5. **媒体库**：网格、上传（按钮+拖拽+粘贴，自动压缩）、复制 Markdown 引用、删除（落库 public/assets/uploads）
6. **顶栏**：logo、回站点、三主题切换、退出登录；移动端可用

## 草稿功能

- schema 加 `draft: z.boolean().default(false)`
- 前台过滤四处：首页最新 / /blog/ 列表 / 文章页 getStaticPaths / search.json 索引（草稿直链 404）
- 现有文章默认已发布，行为不变

## 实施步骤（分阶段 commit）

1. 草稿字段 + 前台过滤 → build 验证
2. `git rm` Sveltia 三件套
3. 边缘函数后端：HMAC 签名工具 + login + 鉴权（各 API 入口校验 Bearer token）+ posts CRUD（服务端统一序列化 frontmatter）+ media（base64 → GitHub Contents API）
4. CMS 前端：骨架（cms.css 复用三主题变量/像素字体/美西螈素材）→ 登录页 → 仪表盘 → 列表 → 编辑器 → 媒体库
5. 本地端到端：edgeone CLI 起本地环境（.dev.vars/本地 env 填账号密码/secret/gh token），`CMS_BRANCH=cms-test` 指向测试分支（gh 创建）真实读写，测完删分支
6. 浏览器全流程截图过目（登录/仪表盘/编辑器/媒体库 × 三主题）+ 程序化验收（登录成败/401/CRUD/上传压缩/草稿过滤）
7. 文档：README-CMS.md（EdgeOne 控制台接入仓库 + 环境变量配置 + 上线步骤，全中文）+ HANDOFF/AGENTS 更新 + bundle 备份

## 验收标准

- 本地：登录成功/失败/限速、token 过期 401、文章增删改查（测试分支真 commit）、图片上传压缩/删除、草稿字段正确
- 前台：草稿不出现于首页/列表/搜索、直链 404；现有文章不受影响；`npm run build` 通过
- 界面三主题截图过目，全站无英文文案
