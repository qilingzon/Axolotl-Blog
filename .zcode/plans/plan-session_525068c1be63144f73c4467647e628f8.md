## Context
在完成了第 17~21 批（KV 零构建上传、进阶工具栏重做、KV 攒批入库、设置按钮强化）的核心功能建设后，我们对边缘函数（`edge-functions/`）、前端应用（`public/admin/`）及测试套件（`scripts/`）进行了深度排查。

## 修复清单与实施设计

### 1. 数据完整性与后端健壮性修复（`edge-functions/api/[[default]].js` 与 `edge-functions/m/[name].js`）
1. **防止入库期间并发写文章数据丢失（Critical）**：
   - 现存 Bug：`handlePostsFlush` 在提交成功后执行 `await kvWritePend(kv, {})`，如果在 Git Data API 网络调用期间（耗时数秒）用户保存了新文章，新文章在 `pend` 里的索引会被无条件抹除成为孤儿数据。
   - 修复：改成增量移除已成功 commit 的 slugs：
     ```javascript
     const latestPend = await kvReadPend(kv);
     for (const it of items) delete latestPend[it.slug];
     await kvWritePend(kv, latestPend);
     ```
2. **修复活跃用户滑续期丢失 KV 标志（Critical）**：
   - 现存 Bug：`api/session` 触发滑续期（剩余时间 < 50%）换发新令牌时，返回体漏掉了 `kv: !!kvStore()`，导致前端 `state.kvAvailable` 变为 `false`，后续写文章自动降级为直接推 GitHub 触发全站重构，使攒批失效。
   - 修复：在续期返回体中补全 `kv: !!kvStore()`。
3. **修复版本回滚后遗留 KV 脏快照（High）**：
   - 现存 Bug：`handleVersionRestore` 将仓库回滚后未调用 `kvForgetPost(kv, slug)`，导致单篇 GET 依然读回滚前的 KV 脏快照，且下次 flush 会把脏快照反向覆盖回仓库。
   - 修复：回滚成功后调用 `const kv = kvStore(); if (kv) await kvForgetPost(kv, slug);`。
4. **修复登录防爆破锁定计数过期后输错一次即再锁 15 分钟（Medium）**：
   - 现存 Bug：15 分钟锁定期满后计数器未重置，合法用户只要输错一次就会因为 `count >= 5` 再次锁死 15 分钟。
   - 修复：在 `recordFail` 中增加判断：若当前时间已超过原锁定截止时间，则先将 `count` 归零重计。
5. **接口请求体异常容错（Medium）**：
   - 现存 Bug：`handlePostItem` PUT 与 `handleUploadMedia` POST 直接调用裸 `await request.json()`，畸形报文导致 500 未捕获异常。
   - 修复：补齐 `try / catch` 统一返回标准的 400 格式错误。
6. **修复 `/m/` 路由长缓存与同名图片覆盖更新冲突（Medium）**：
   - 现存 Bug：`/m/[name].js` 设置了 `immutable` 长缓存 1 年，但后端允许同名图片覆盖上传，覆盖后访客 CDN 与浏览器不回源更新。
   - 修复：移除 `immutable`，将 `max-age` 调整为兼顾性能与可更新的合理策略。

### 2. 前端交互与体验缺陷修复（`public/admin/app.js`）
1. **单图删除与批量删除引用安全保护（High）**：
   - 现存 Bug ①：单图删除 `deleteImageFlow` 引用检查只匹配了 `/assets/uploads/`，漏掉了 KV 路径 `/m/`，导致新图被误判为未引用。
   - 现存 Bug ②：批量删除弹窗文案承诺“被文章引用的会保留”，但实际代码并未检查引用，直接全量物理删除。
   - 修复：
     - 单图删除引用正则增加 `/m/`；
     - 批量删除利用已有的 `refsMap` 过滤掉正在被引用的图片，仅删除未引用图片，并向用户提示已保护跳过引用的图片数量。
2. **快捷键 Ctrl+S 作用域补全（Medium）**：
   - 现存 Bug：保存监听仅绑在正文卡片 `#editor-card` 上，光标在标题、描述、slug 或标签输入框中时按 Ctrl+S 无法拦截，直接唤起浏览器“网页另存为”系统弹窗。
   - 修复：事件冒泡监听升级绑定在包含所有卡片的 `.editor-grid` 上。
3. **修复自动暂存定时器泄露（Medium）**：
   - 现存 Bug：每次进入编辑器都启动 `setInterval(..., 30000)` 但未记录清理，页面多篇文章切换后产生多个驻留定时器争抢 `localStorage`。
   - 修复：维护全局 `autodraftTimer`，在路由离开或重新进入时先 `clearInterval`。
4. **修复小白模式代码块语言抹除与表格首尾列截断（Medium）**：
   - 现存 Bug ①：`parseBlocks` 解析代码块时直接丢弃了首行语言标（如 ```python），序列化时变成无语言裸代码块。
   - 现存 Bug ②：`parseRow` 假定表格行首尾必有 `|` 而盲目 `shift()` 和 `pop()`，标准紧凑 Markdown 表格（如 `A | B`）会被截断首尾列。
   - 修复：保留 `b.lang`；解析表格行时检测首尾是否有 `|` 再安全裁剪。
5. **图片重命名弹窗交互优化（Low/UX）**：
   - 输入框支持 Enter 键直接回车提交；输入为空或名称未改变时给予明确红字错误提示。
6. **离开未修改文章时清空 `editorGuard` 闭包（Low/UX）**。

### 3. 自动化测试网大幅扩充（`scripts/cms-selftest.mjs`）
将纯函数测试覆盖从 **27 项扩充至 35+ 项**，增加此前未覆盖的盲区：
- `safeEqual` 防时序侧信道字符串比对正确性（相同、不同长度、单字符差异、空串）
- `b64ToBytes` 对 GitHub Contents API 带换行符的 base64 容错清洗
- `stripQuotes` 单引号还原（防止连续保存时 YAML 引号指数级翻倍）
- `postRefsImage` 跨格式图片引用扫描测试（精准匹配 `/assets/uploads/` 与 `/m/`）
- `parseBlocks` / `blocksToMarkdown` 代码块语言标签保真测试
- `parseBlocks` 表格无外边框管道符解析测试
- `posts-flush` 增量移除索引算法纯函数测试

1. **静态代码与语法检查**：
   `node --check` 检查所有修改后的 JS 文件；
2. **自动化单元测试全覆盖**：
