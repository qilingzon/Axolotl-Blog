# 原创吉祥物替换 + 页脚备案号（商用去风险）

## 背景

全站七只螈 + 7 个 favicon 都源自从 AxolotlLauncher.exe 提取的第三方图标（仓库里还留有 `design-assets/exe-icon-256-0.png` 提取产物），商用即版权雷区。现有重上色管线（`generate-variants.mjs`，亮度阶梯重映射）可以喂任何合规底图，**换一张原创底图 = 全家桶一次换干净**，颜色家族、组件、文章数据全都不用动。

## 一、原创像素螈（核心工作）

**绘制方式**：新建 `scripts/draw-axolotl.mjs`，在 64×48 逻辑网格上逐像素手绘（每格 4×4 真像素 → 输出 **256×191** 8-bit RGBA PNG，与现图完全同规格——三处硬编码比例、favicon 合成逻辑全部不用改）。画风保持圆润卡通风、粉色系，构图贴近现有形象（大眼 + 三根外鳃 + 尾巴），确保换图后站点气质不变。

**管线兼容构图**（现有算法的隐含要求，绘制时遵守）：
- 彩色身体 + 中性色（灰白）眼睛与高光（饱和度 <0.15 的像素不被重上色，眼睛才能在七个变体里保持原样）
- 外鳃用比身体更暗的色带（cyan 变体的粉鳃逻辑依赖"最暗彩带=鳃"）
- 纯透明背景

**流程**：先画 **3 个候选**（不同姿态/配色微差）→ 生成图直接展示给你挑 → 选中的精修一轮 → 定稿。

**接入**：
- 定稿图存 `public/assets/axolotl-base.png`（不覆盖旧文件名）
- `generate-variants.mjs`：输入路径改指 base；RAMPS **新增 pink 锚点**（从仓库里现成的原创 `favicon.svg` 取粉色值 #F5538F/#F9A8C9）→ 首次输出 `axolotl-pink.png`，七色全部出自原创底图
- 全站引用替换（探索报告已列全）：`Axolotl.astro` / `AxolotlRandom.astro` 的 pink 项、`BaseLayout.astro` preload+splash 数组、`public/admin/app.js` ACCENTS[0]、favicon 主图改用脚本生成的新 pink
- **第三方素材出库**：git rm `public/assets/axolotl-launcher.png`、`design-assets/exe-icon-256-0.png`、`design-assets/make-purple.ps1`（purple 也变为 base 重上色产物，来源干净）
- 变体 id（pink/purple/wild/cyan/gold/blue/green）与文章 frontmatter **完全不动**——内容零影响
